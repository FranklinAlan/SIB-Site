CHANGING THE TWO SIB VIDEOS

1. Replace either MP4 in videos/ using the same filenames:
   example-1.mp4
   example-2.mp4
   Use MP4 files that play in Chrome (H.264 video and AAC audio are suitable).

2. Confirm each replacement’s authenticity category. The current first clip
   is labeled real and the second is labeled manipulated.

3. Open index.html in a plain-text/code editor and search for:
   VIDEO ANSWER KEY

   The editable block is:
   const clips = [
     {src:'videos/example-1.mp4',answer:'real'},
     {src:'videos/example-2.mp4',answer:'manipulated'}
   ];

   Use only 'real' or 'manipulated' for answer. The results and replay labels
   both use this single key. Replacing a video does not change its label.

4. Update the About this activity source note if the new clips come from
   different materials. Update the README source note too.

5. Open index.html, play both videos, submit both judgments, and check that
   the revealed answers are correct.

6. Commit and push the changed files to GitHub. Check the published page
   after GitHub Pages updates.

This version supports replacing either of the two clips. Adding more clips
would also require updating the progress and replay controls in index.html.
