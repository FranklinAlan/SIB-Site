CLASSROOM USE
Read teacher-guide.html first. Students make individual first responses.
If using the independent cases, give assessment.html after the game and BEFORE
peer discussion or the debrief. It is intentionally not an automatic game stage.
Then debrief with the contrasting example in the guide.

Plan 15–20 minutes of game time, roughly 5–8 minutes for the optional cases,
and 3–5 minutes of discussion. These are estimates to check during a walkthrough.
All case details are fictional. This is guided evidence evaluation, not a secure exam.

RECORDS
Game and assessment save separately in this browser. Nothing is uploaded or
submitted automatically. Use CSV, JSON, or printing when you need a retained
record under your authorized classroom/research procedure. No name is requested;
the assessment offers an optional instructor-assigned code.

A game CSV has one row. An assessment CSV has three rows for ONE student's
three cases. Optional experience ratings repeat on those three rows; analyze
those ratings once per student. These are not three independent participants.

Start over resets the game. New attempt resets the assessment. Save needed
records before resetting. Version 3 uses its own storage keys, so older-version
choices are not silently treated as responses to the revised tasks.

EVALUATION LIMITS
The game is practice. A first pilot can describe feasibility and performance
on these few fresh cases. It cannot establish improvement, broad media literacy,
calibration, lasting transfer, or the benefit of the game format on its own.
No confidence scale, PCT elicitation, extra stations, or click-history logging
has been added. See the guide for the proposed reason rubric and study limits.
